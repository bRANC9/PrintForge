{% comment %} Render findings of the selected version -- what the render itself noticed about the model it just produced. This is the only place `validation_json["warnings"]` is shown, and it is deliberately OUTSIDE any `x-if`. A prompt-generated version has no source mesh, so the old home for these strings (inside the source-mesh panel in designs/viewer.html) mounted for none of them: the 90 mm cookie press that rendered 195 mm tall passed every meshcheck, reported "printable", and warned nobody (docs/model-matrix-test-round.md 2.). Read as one list (`versionWarnings`), split into three boxes by `warningKind`, which only recognises the sentence openings the backend producers use -- the numbers stay in the text, nothing is re-parsed here. Keyed on the selected version like the panels below, so switching versions cannot leave a previous version's findings (or acknowledgement) on screen. {% endcomment %}
